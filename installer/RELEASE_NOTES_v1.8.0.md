# Desktop Toolkit 1.8.0

## 自研局域网远程控制（替代 RustDesk 主路径）

同一 Wi‑Fi 下即可互控，不依赖内嵌 RustDesk：

1. **被控端**：设密码 → 开启被控 → 把本机局域网 IP 发给对方  
2. **主控端**：填对方 IP + 密码 → 连接 → 在画面里用鼠标键盘操作  

- 默认端口 **8766**（与文件共享 8765 错开）  
- Win ↔ Mac 双向  
- Mac 需授权：屏幕录制 + 辅助功能  
- Windows 防火墙需放行 8766  

RustDesk 仍可作为备用（不再作为默认连接方式）。
