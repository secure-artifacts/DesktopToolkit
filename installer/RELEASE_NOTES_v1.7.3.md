# Desktop Toolkit 1.7.3

## macOS

- **DMG 安装包**（推荐）：打开后把 `DesktopToolkit.app` 拖进「应用程序」，用法类似 RustDesk
- 仍提供 `.zip`：解压后同样拖进「应用程序」
- 应用内「检查更新」优先下载 DMG；ZIP 会尝试自动复制到「应用程序」
- 更新提示会同时显示「当前版本」和「远程最新版本」，避免误判

## Windows

- 同版本 Windows setup / portable

## 说明

- macOS 包暂未 Apple 公证；首次打开若提示未验证开发者，请右键 App →「打开」
